## 🎓 The 4D Framework

All prompts in this library follow the **Anthropic 4D Framework** for effective AI collaboration:

1. **Delegation** - What to delegate to AI vs keep human
2. **Description** - How to write clear, specific prompts
3. **Discernment** - How to evaluate and validate AI outputs
4. **Diligence** - Building sustainable, repeatable systems
